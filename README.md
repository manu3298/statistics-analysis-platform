# StatMutai Analytics

A statistics and probability analysis website designed for students and data learners.

## Features
- Descriptive statistics calculator
- Data entry with examples
- Histograms and trend charts
- Probability calculations
- Tutorials and learning support
- Help section with common errors and solutions

## Tech stack
- React
- Vite
- Tailwind CSS
- Recharts

## Run locally
```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal, typically:
```bash
http://localhost:3000
```

## Project goals
This project is designed to support:
- automatic descriptive statistical analysis
- chart generation for data interpretation
- probability problem solving
- beginner-friendly guidance and examples
- explanations of errors and recommended fixes
